# Instalacja Bot Udziały

## Krok 1: Zainstaluj Python

Otwórz PowerShell i wpisz:

```
winget install Python.Python.3.11
```

Zamknij i otwórz PowerShell ponownie.

## Krok 2: Zainstaluj bota

```
pip install udzialy-bot
```

## Krok 3: Konfiguracja

```
udzialy setup
```

## Krok 4: Uruchom

```
udzialy run
```
